# Security

- This skill contains design rules only. It does not execute code by itself.
- The audit script in `references/anti-ai.md` is meant for the browser console. It reads the page's computed styles and returns a result there. It makes no network requests and sends no data anywhere.
- The grep commands in the same file only read local files.
- Review the contents before installing, starting with `SKILL.md`. Any skill shapes what your agent does.

To report a problem, open an issue on the repository.
